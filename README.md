# Zovance Automation Library

Welcome to the **Zovance Automation Library**—a premium, enterprise-grade suite of 100 business automations and AI agent architectures.

## Philosophy
Every automation in this library belongs to exactly one category based on core business functions (not technologies). The repository is designed to be highly modular, standardized, and immediately deployable.

## Directory Structure
- **Core Categories (`01_SALES_AUTOMATION` to `10_AI_AGENTS`)**: Contains 10 automations each.
- **COMMON_COMPONENTS**: Reusable modules, error handlers, and utility workflows.
- **SHARED_PROMPTS**: Standard prompt templates grouped by business vertical.
- **CREDENTIAL_TEMPLATES**: Standard API connection profiles.
- **CLIENT_TEMPLATES**: Standard client onboarding, agreement, and SOW documents.
- **DEMOS**: Ready-to-use demo materials for client presentations.
- **ARCHIVE**: Legacy workflow storage.

## Automation Standard Layout
Every automation is formatted using the exact same standard folder layout:
1. `01_Workflow/`: Importable JSON workflow configuration files.
2. `02_Documentation/`: In-depth developer guides (Setup, Inputs, Outputs, config tables).
3. `03_Prompts/`: Large Language Model prompt files and JSON schema rules.
4. `04_Testing/`: Sample mock inputs/outputs and validation metrics.
5. `05_Client/`: Business collateral including sales decks, demo scripts, pricing guidelines, and target industry profiles.
6. `06_Assets/`: Media files (Videos, Images, Screenshots, and Icons).
7. `CHANGELOG.md`: Clean version logging.
